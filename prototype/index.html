Gen75 Studio Prototipe · tidak terhubung ke keyboard

Keymap

Pilih tombol di kanvas, lalu klik keycode di palet. Layout digambar dari definisi JSON (bukan gambar statis). Label tombol adalah contoh; aplikasi nyata membaca keymap dari perangkat.

Layer

Lighting

Menu di bawah dibangun otomatis dari bagian menus pada JSON: tipe kontrol, rentang, daftar efek, dan aturan showIf semuanya dibaca dari definisi. Pratinjau disederhanakan.

Fungsi Gen 75

11 keycode khas Gen 75 dari definisi. Di VIA standar keycode ini hanya berupa label; di sini disertai penjelasan dan pemasangan satu klik ke tombol.

Konfigurasi hanya lewat kabel USB. Pindah mode (2.4G/BLE/USB) dilakukan dengan menekan tombol yang dipasangi keycode di keyboard; app tidak bisa "menekannya" dari layar karena protokol VIA tidak punya perintah itu.
