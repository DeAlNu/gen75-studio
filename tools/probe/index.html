Probe Gen 75

Halaman ini hanya membaca data dari keyboard. Tidak ada perintah tulis, reset, atau lompat ke bootloader yang dikirim. Hasilnya dipakai untuk memastikan protokol firmware sebelum aplikasi utama dibuat.

Mode simulasi aktif: perangkat di bawah ini palsu dan hanya ada di halaman ini.
Browser ini tidak mendukung WebHID. Pakai Chrome atau Edge versi terbaru.

Persiapan

  • Sambungkan keyboard lewat kabel USB (mode kabel).
  • Tutup tab VIA dan aplikasi lain yang memakai keyboard, supaya perangkat tidak terkunci.
  • Klik Sambungkan, lalu pilih perangkat di dialog browser.
